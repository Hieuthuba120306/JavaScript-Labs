Giới thiệu dự án
Mục tiêu của dự án là thực hành các kiến thức JavaScript từ nền tảng
ngôn ngữ đến thao tác với cấu trúc trang web, xử lý sự kiện và sử dụng
thư viện jQuery. Thông qua ba bài Lab, sinh viên từng bước làm quen với
cách xây dựng các chức năng tương tác trên website -- những kỹ năng có
thể ứng dụng trong quá trình phát triển website thương mại điện tử.
Nội dung các bài thực hành
Lab 08 -- JavaScript 1: Language Foundations
Tập trung vào những kiến thức nền tảng của JavaScript:
- Làm quen với cú pháp và cách nhúng JavaScript vào trang HTML.
- Sử dụng biến, kiểu dữ liệu, hàm và các cấu trúc điều khiển cơ bản.
- Thực hành với String, Date, Array và Object.
- Xây dựng và sử dụng hàm để tổ chức, tái sử dụng mã nguồn.
- Sử dụng Browser Console để kiểm tra kết quả và hỗ trợ tìm lỗi.
Lab 09 -- JavaScript 2: DOM and Events
Tìm hiểu cách JavaScript tương tác với nội dung và hành vi của trang
web:
- Truy xuất và lựa chọn phần tử HTML thông qua DOM.
- Đọc, thay đổi nội dung, thuộc tính và kiểu hiển thị của phần tử.
- Tạo, thêm và xóa các phần tử HTML.
- Xử lý sự kiện như click, mouseover và mouseout.
- Làm việc với Form và kiểm tra dữ liệu đầu vào.
- Sử dụng Developer Tools để kiểm tra và gỡ lỗi sự kiện.
Lab 10 -- JavaScript 3: jQuery
Tiếp cận thư viện jQuery để đơn giản hóa các thao tác trên trang web:
- Tích hợp và sử dụng thư viện jQuery.
- Sử dụng Selectors để truy xuất phần tử HTML.
- Xử lý sự kiện bằng jQuery.
- Thêm và thao tác các phần tử DOM.
- Tạo hiệu ứng và hoạt ảnh cho các thành phần giao diện.
- Thực hiện GET Requests và xử lý kết quả trả về thông qua jqXHR.

Cấu trúc bên trong từng thư mục Lab có thể bao gồm các thư mục
Exercise, tệp HTML, JavaScript, CSS và tài nguyên đi kèm.
Công nghệ sử dụng
- HTML5: Xây dựng cấu trúc nội dung trang web.
- CSS3: Thiết kế giao diện, bố cục responsive và hiệu ứng chuyển
  động.
- JavaScript: Xử lý logic và tương tác trên trình duyệt.
- jQuery: Hỗ trợ truy xuất DOM, xử lý sự kiện, hiệu ứng và yêu cầu
  dữ liệu.
- Git & GitHub: Quản lý mã nguồn và lưu trữ dự án.
- GitHub Pages: Triển khai trang web để truy cập trực tuyến.
Cách chạy dự án
Xem trang chủ
1. Clone repository về máy:
   git clone [URL_REPOSITORY]
2. Mở thư mục JavaScript-Labs bằng Visual Studio Code.
3. Mở tệp index.html bằng trình duyệt hoặc sử dụng tiện ích Live
   Server.
Xem từng bài Lab
Mở thư mục Lab08, Lab09 hoặc Lab10, sau đó chạy tệp HTML tương ứng
với bài thực hành cần xem. Một số bài có thể cần chạy bằng Live Server
để bảo đảm các tài nguyên và yêu cầu dữ liệu hoạt động đúng.
Định hướng ứng dụng
Các kiến thức trong ba bài Lab là nền tảng để phát triển những chức năng
thường gặp trên website thương mại điện tử, ví dụ:
- Kiểm tra và xác thực thông tin trong biểu mẫu đăng ký, đăng nhập
  hoặc đặt hàng.
- Cập nhật nội dung sản phẩm và phản hồi giao diện theo thao tác người
  dùng.
- Xây dựng các tương tác trên giỏ hàng.
- Tạo hiệu ứng giúp giao diện trực quan và dễ sử dụng hơn.
- Gửi yêu cầu và hiển thị dữ liệu nhận được từ dịch vụ bên ngoài.
Đây là những hướng ứng dụng có thể phát triển từ kiến thức đã học, không
đồng nghĩa tất cả chức năng trên đã được triển khai thành một website
thương mại điện tử hoàn chỉnh.
