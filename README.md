# JavaScript Labs — Learning Journal

A personal homepage for the JavaScript coursework, with quick indexes for the Lab 08, Lab 09, and Lab 10 walkthroughs. The lab `index.html` files only link to the original lab pages; the existing exercises and source files are unchanged.

## Preview locally

From this directory, start a small static server:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000> in a browser. Stop the server with `Ctrl+C`.
